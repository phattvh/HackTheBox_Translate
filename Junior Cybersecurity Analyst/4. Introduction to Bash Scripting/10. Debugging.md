# Debugging

Bash mang lại khả năng rất tốt để tìm kiếm, theo dõi và khắc phục lỗi trong mã nguồn. Thuật ngữ gỡ lỗi (debugging) có thể mang nhiều sắc thái ý nghĩa khác nhau, tuy nhiên [gỡ lỗi trong Bash](https://tldp.org/LDP/Bash-Beginners-Guide/html/sect_02_03.html) (Bash debugging) về bản chất là quá trình loại bỏ các lỗi (bugs) khỏi mã nguồn. Quá trình này có thể được thực hiện theo nhiều cách, chẳng hạn như kiểm tra lỗi chính tả hoặc phân tích mã nguồn nhằm truy vết và xác định nguyên nhân phát sinh một lỗi cụ thể.

Quy trình này cũng được ứng dụng để tìm kiếm lỗ hổng trong các chương trình. Ví dụ, chúng ta có thể thử kích hoạt lỗi bằng nhiều loại dữ liệu đầu vào khác nhau và theo dõi cách CPU xử lý chúng thông qua hợp ngữ (assembler), từ đó tìm ra cách can thiệp vào luồng xử lý lỗi để chèn mã của riêng mình và buộc hệ thống thực thi. Chủ đề này sẽ được đề cập và phân tích chuyên sâu ở các mô-đun khác. Bash cho phép chúng ta gỡ lỗi mã nguồn thông qua hai tùy chọn `-x` (`xtrace`) và `-v`. Hãy cùng xem một ví dụ với script `CIDR.sh`:

#### Gỡ lỗi CIDR.sh (CIDR.sh - Debugging)

```shellsession
phat2007dhsp@htb[/htb]$ bash -x CIDR.sh
+ '[' 0 -eq 0 ']'
+ echo -e 'You need to specify the target domain.\n'
You need to specify the target domain.

+ echo -e Usage:
Usage:
+ echo -e '\tCIDR.sh <domain>'
	CIDR.sh <domain>
+ exit 1
```

Tại đây, Bash hiển thị chính xác hàm hoặc câu lệnh nào đã được thực thi kèm theo các giá trị cụ thể. Điều này được đánh dấu bằng dấu cộng (`+`) ở đầu mỗi dòng. Nếu muốn xem toàn bộ mã nguồn của một đoạn lệnh hay hàm cụ thể, chúng ta có thể kết hợp thêm tùy chọn `-v` để hiển thị đầu ra chi tiết hơn:

#### Gỡ lỗi chi tiết CIDR.sh (CIDR.sh - Verbose Debugging)

```shellsession
phat2007dhsp@htb[/htb]$ bash -x -v CIDR.sh
#!/bin/bash

# Check for given argument
if [ $# -eq 0 ]
then
    echo -e "You need to specify the target domain.\n"
    echo -e "Usage:"
    echo -e "\t$0 <domain>"
    exit 1
else
    domain=$1
fi
+ '[' 0 -eq 0 ']'
+ echo -e 'You need to specify the target domain.\n'
You need to specify the target domain.

+ echo -e Usage:
Usage:
+ echo -e '\tCIDR.sh <domain>'
	CIDR.sh <domain>
+ exit 1
```

So với chế độ gỡ lỗi thông thường, tùy chọn `-v` giúp chúng ta quan sát được toàn bộ đoạn mã nguồn vừa được trình thông dịch nạp vào xử lý, tiếp theo sau đó là từng bước thực thi chi tiết tương ứng.
