# Conditional Execution

Thực thi có điều kiện (Conditional execution) cho phép chúng ta kiểm soát luồng hoạt động của script dựa trên các điều kiện khác nhau. Đây là một trong những thành phần cốt lõi, bởi nếu không có nó, chúng ta chỉ có thể thực thi tuần tự từng lệnh một từ đầu đến cuối.

Khi thiết lập các điều kiện khác nhau, chúng ta chỉ định rõ hàm hoặc đoạn mã nào sẽ được thực thi ứng với một giá trị cụ thể. Khi thỏa mãn một điều kiện nhất định, chỉ đoạn mã của điều kiện đó được chạy và các nhánh còn lại sẽ bị bỏ qua. Ngay khi đoạn mã trong nhánh điều kiện hoàn tất, các lệnh tiếp theo bên ngoài cấu trúc điều kiện sẽ tiếp tục được thực thi. Chúng ta hãy xem lại phần đầu tiên của script `CIDR.sh` để cùng phân tích.

#### Script.sh

```bash
#!/bin/bash

# Check for given argument
if [ $# -eq 0 ]
then
    echo -e "You need to specify the target domain.\n"
    echo -e "Usage:"
    echo -e "\t$0 <domain>"
    exit 1
else
    domain=$1
fi

<SNIP>
```

Tóm lại, đoạn mã trên hoạt động với các thành phần sau:

- `#!/bin/bash`: Shebang.
- `if-else-fi`: Thực thi có điều kiện (Conditional execution).
- `echo`: In thông tin ra màn hình.
- `$#` / `$0` / `$1`: Các biến đặc biệt (Special variables).
- `domain`: Biến người dùng định nghĩa (Variables).

Các điều kiện trong thực thi có điều kiện có thể được xác định bằng cách sử dụng biến (`$#`, `$0`, `$1`, `domain`), giá trị số (`0`) và chuỗi ký tự, như chúng ta sẽ thấy trong các ví dụ tiếp theo. Những giá trị này được so sánh thông qua các toán tử so sánh (`-eq`), nội dung mà chúng ta sẽ tìm hiểu chi tiết ở các phần sau.

## Shebang

Dòng Shebang luôn nằm ở dòng đầu tiên của mỗi script và luôn bắt đầu bằng ký tự `#!`. Dòng này chứa đường dẫn tuyệt đối đến trình thông dịch được chỉ định (`/bin/bash`) dùng để thực thi script. Chúng ta cũng có thể sử dụng Shebang để chỉ định các trình thông dịch khác như Python, Perl hay nhiều ngôn ngữ khác:

```python
#!/usr/bin/env python
```

```perl
#!/usr/bin/env perl
```

## If-Else-Fi

Một trong những tác vụ lập trình cơ bản nhất là kiểm tra các điều kiện khác nhau để đưa ra hướng xử lý phù hợp. Việc kiểm tra điều kiện trong các ngôn ngữ lập trình và ngôn ngữ kịch bản thường có hai dạng phổ biến: cấu trúc điều kiện `if-else` và cấu trúc rẽ nhánh `case`. Dưới dạng mã giả (pseudo-code), điều kiện `if` mang ý nghĩa như sau:

#### Mã giả (Pseudo-Code)

```bash
if [ số lượng đối số truyền vào bằng 0 ]
then
    In ra: "You need to specify the target domain."
    In ra: "<dòng trống>"
    In ra: "Usage:"
    In ra: "   <tên script> <domain>"
    Thoát script với mã lỗi
else
    Biến "domain" đóng vai trò là bí danh lưu giá trị đối số truyền vào
kết thúc điều kiện if
```

Theo mặc định, một cấu trúc điều kiện `if-else` có thể chỉ chứa một mệnh đề `if` duy nhất, như minh họa trong ví dụ dưới đây.

#### If-Only.sh

```bash
#!/bin/bash

value=$1

if [ $value -gt "10" ]
then
    echo "Given argument is greater than 10."
fi
```

#### Thực thi If-Only.sh (If-Only.sh - Execution)

```shellsession
phat2007dhsp@htb[/htb]$ bash if-only.sh 5

phat2007dhsp@htb[/htb]$ bash if-only.sh 12
Given argument is greater than 10.
```

Khi bổ sung thêm `elif` hoặc `else`, chúng ta tạo ra các nhánh xử lý thay thế cho các giá trị hoặc trạng thái cụ thể. Nếu một giá trị không thỏa mãn trường hợp đầu tiên, nó sẽ được bắt và xử lý bởi các trường hợp tiếp theo.

#### If-Elif-Else.sh

```bash
#!/bin/bash

value=$1

if [ $value -gt "10" ]
then
    echo "Given argument is greater than 10."
elif [ $value -lt "10" ]
then
    echo "Given argument is less than 10."
else
    echo "Given argument is not a number."
fi
```

#### Thực thi If-Elif-Else.sh (If-Elif-Else.sh - Execution)

```shellsession
phat2007dhsp@htb[/htb]$ bash if-elif-else.sh 5
Given argument is less than 10.

phat2007dhsp@htb[/htb]$ bash if-elif-else.sh 12
Given argument is greater than 10.

phat2007dhsp@htb[/htb]$ bash if-elif-else.sh HTB
if-elif-else.sh: line 5: [: HTB: integer expression expected
if-elif-else.sh: line 8: [: HTB: integer expression expected
Given argument is not a number.
```

Chúng ta có thể mở rộng script ban đầu và chỉ định nhiều điều kiện khác nhau. Đoạn mã có thể được cấu trúc như sau:

#### Thiết lập nhiều điều kiện (Several Conditions - Script.sh)

```bash
#!/bin/bash

# Check for given argument
if [ $# -eq 0 ]
then
    echo -e "You need to specify the target domain.\n"
    echo -e "Usage:"
    echo -e "\t$0 <domain>"
    exit 1
elif [ $# -eq 1 ]
then
    domain=$1
else
    echo -e "Too many arguments given."
    exit 1
fi

<SNIP>
```

Ở đây, chúng ta định nghĩa thêm một điều kiện (`elif [ <condition> ]; then`) nhằm in ra thông báo (`echo -e "..."`) cho biết chúng ta đã truyền nhiều hơn một đối số và thoát chương trình với mã lỗi (`exit 1`).
