# Comparison Operators

Để so sánh các giá trị cụ thể với nhau, chúng ta cần sử dụng các thành phần gọi là toán tử so sánh ([comparison operators](https://www.tldp.org/LDP/abs/html/comparison-ops.html)). Các toán tử so sánh được dùng để xác định cách thức đối chiếu giữa những giá trị được chỉ định. Chúng ta phân loại các toán tử này thành 4 nhóm chính:

- Toán tử chuỗi (String operators)
- Toán tử số nguyên (Integer operators)
- Toán tử tệp tin (File operators)
- Toán tử boolean và toán tử logic (Boolean and logical operators)

---

## String Operators

Khi so sánh các chuỗi ký tự, chúng ta xác định trước nội dung chuỗi mong muốn để kiểm tra giá trị tương ứng.

| Toán tử (Operator) | Mô tả (Description) |
| :---: | :--- |
| `==` | Bằng với |
| `!=` | Không bằng với (khác) |
| `<` | Nhỏ hơn theo thứ tự bảng chữ cái ASCII |
| `>` | Lớn hơn theo thứ tự bảng chữ cái ASCII |
| `-z` | Kiểm tra chuỗi có rỗng hay không (null) |
| `-n` | Kiểm tra chuỗi có không rỗng hay không (not null) |

Cần lưu ý rằng chúng ta nên đặt biến đại diện cho đối số truyền vào (`$1`) trong cặp dấu ngoặc kép (`"$1"`). Thao tác này báo cho Bash biết nội dung của biến cần được xử lý dưới dạng chuỗi ký tự nhằm tránh phát sinh lỗi khi đối số bị để trống hoặc chứa khoảng trắng:

```bash
#!/bin/bash

# Check the given argument
if [ "$1" != "HackTheBox" ]
then
    echo -e "You need to give 'HackTheBox' as argument."
    exit 1
elif [ $# -gt 1 ]
then
    echo -e "Too many arguments given."
    exit 1
else
    domain=$1
    echo -e "Success!"
fi
```

Toán tử so sánh chuỗi `<` và `>` chỉ hoạt động chính xác bên trong cặp dấu ngoặc vuông kép `[[ <condition> ]]`. Chúng ta có thể tra cứu bảng mã ASCII trên Internet hoặc bằng lệnh sau trong terminal:

```shellsession
phat2007dhsp@htb[/htb]$ man ascii
```

#### Bảng mã ASCII (ASCII Table)

| Thập phân (Decimal) | Thập lục phân (Hexadecimal) | Ký tự (Character) | Mô tả (Description) |
| :---: | :---: | :---: | :--- |
| 0 | 00 | NUL | End of a string |
| ... | ... | ... | ... |
| 65 | 41 | A | Capital A |
| 66 | 42 | B | Capital B |
| 67 | 43 | C | Capital C |
| 68 | 44 | D | Capital D |
| ... | ... | ... | ... |
| 127 | 7F | DEL | Delete |

ASCII là viết tắt của American Standard Code for Information Interchange, đại diện cho chuẩn mã hóa ký tự 7-bit. Do mỗi bit có thể nhận hai giá trị (0 hoặc 1), bảng mã có tổng cộng 128 tổ hợp bit khác nhau, tương ứng với các số nguyên thập phân từ 0 đến 127 hoặc giá trị thập lục phân từ 00 đến 7F. Trong đó, 32 mã ký tự ASCII đầu tiên được dành riêng làm các ký tự điều khiển ([control characters](https://en.wikipedia.org/wiki/Control_character)).

## Integer Operators

So sánh số nguyên rất hữu ích khi chúng ta cần đối chiếu các giá trị số cụ thể. Dựa vào kết quả so sánh, chúng ta xác định các bước xử lý và câu lệnh tiếp theo mà script cần thực thi.

| Toán tử (Operator) | Mô tả (Description) |
| :---: | :--- |
| `-eq` | Bằng với (`equal to`) |
| `-ne` | Không bằng với (`not equal to`) |
| `-lt` | Nhỏ hơn (`less than`) |
| `-le` | Nhỏ hơn hoặc bằng (`less than or equal to`) |
| `-gt` | Lớn hơn (`greater than`) |
| `-ge` | Lớn hơn hoặc bằng (`greater than or equal to`) |

```bash
#!/bin/bash

# Check the given argument
if [ $# -lt 1 ]
then
    echo -e "Number of given arguments is less than 1"
    exit 1
elif [ $# -gt 1 ]
then
    echo -e "Number of given arguments is greater than 1"
    exit 1
else
    domain=$1
    echo -e "Number of given arguments equals 1"
fi
```

## File Operators

Các toán tử tệp tin giúp chúng ta kiểm tra sự tồn tại của tệp tin hoặc xác minh các quyền truy cập cụ thể trên hệ thống tệp.

| Toán tử (Operator) | Mô tả (Description) |
| :---: | :--- |
| `-e` | Kiểm tra tệp tin có tồn tại hay không |
| `-f` | Kiểm tra đối tượng có phải là tệp tin thông thường hay không |
| `-d` | Kiểm tra đối tượng có phải là thư mục hay không |
| `-L` | Kiểm tra đối tượng có phải là liên kết tượng trưng (symbolic link) hay không |
| `-N` | Kiểm tra tệp tin có bị chỉnh sửa sau lần đọc gần nhất hay không |
| `-O` | Kiểm tra người dùng hiện tại có phải là chủ sở hữu của tệp tin hay không |
| `-G` | Kiểm tra nhóm của tệp tin có trùng với nhóm của người dùng hiện tại hay không |
| `-s` | Kiểm tra kích thước tệp tin có lớn hơn 0 byte hay không |
| `-r` | Kiểm tra tệp tin có quyền đọc hay không |
| `-w` | Kiểm tra tệp tin có quyền ghi hay không |
| `-x` | Kiểm tra tệp tin có quyền thực thi hay không |

```bash
#!/bin/bash

# Check if the specified file exists
if [ -e "$1" ]
then
    echo -e "The file exists."
    exit 0
else
    echo -e "The file does not exist."
    exit 2
fi
```

## Boolean and Logical Operators

Khi sử dụng các toán tử logic, kết quả trả về sẽ là giá trị boolean `true` hoặc `false`. Bash cho phép chúng ta so sánh chuỗi ký tự bằng cách sử dụng cặp dấu ngoặc vuông kép `[[ <condition> ]]`. Dựa trên việc phép so sánh có khớp hay không, chúng ta nhận về giá trị boolean tương ứng:

```bash
#!/bin/bash

# Check the boolean value
if [[ -z $1 ]]
then
    echo -e "Boolean value: True (is null)"
    exit 1
elif [[ $# > 1 ]]
then
    echo -e "Boolean value: True (is greater than)"
    exit 1
else
    domain=$1
    echo -e "Boolean value: False (is equal to)"
fi
```

## Logical Operators

Với các toán tử logic, chúng ta có thể kết hợp nhiều điều kiện bên trong cùng một biểu thức kiểm tra. Khi đó, tất cả điều kiện được chỉ định đều phải thỏa mãn thì đoạn mã tương ứng mới được thực thi.

| Toán tử (Operator) | Mô tả (Description) |
| :---: | :--- |
| `!` | Phủ định logic NOT |
| `&&` | Kết hợp logic AND |
| `\|\|` | Kết hợp logic OR |

```bash
#!/bin/bash

# Check if the specified file exists and if we have read permissions
if [[ -e "$1" && -r "$1" ]]
then
    echo -e "We can read the file that has been specified."
    exit 0
elif [[ ! -e "$1" ]]
then
    echo -e "The specified file does not exist."
    exit 2
elif [[ -e "$1" && ! -r "$1" ]]
then
    echo -e "We don't have read permission for this file."
    exit 1
else
    echo -e "Error occured."
    exit 5
fi
```
